# Хронологический журнал изменений (CHANGELOG)

## [2026-10-11] Инициализация системы контроля версий и аудит

### Исправлено (fix):
- **Сбой отображения версии «0.0.0» и зависание обновления:**
  - Установлена причина: `opkg update` зависал на обращении к недоступному зеркалу `http://bin.entware.net`, удерживая блокировку `/opt/tmp/opkg.lock`.
  - Удалены зависшие процессы и снята блокировка.
  - Настроен `/opt/etc/wgetrc` с жесткими таймаутами (`timeout = 15`, `read_timeout = 10`, `tries = 2`).
  - Версия в админке восстановилась до актуальной **1.3.1**.
- **Восстановление консольного доступа SSH (порт 222):**
  - Поднят демон Entware dropbear на порту 222.
  - Добавлен автоматический контроль запуска dropbear при старте службы.

### Организовано (feat):
- **Система контроля версий через Git:**
  - Настроен локальный репозиторий Git в `c:\_CODE\Utilites\keenetic`.
  - Все пароли вынесены в исключённый `.env` файл на базе шаблона `.env.example`.
  - Создан `.gitignore` для защиты секретов, временных файлов и логов.
  - Написан модуль `router_env.py` для безопасного чтения реквизитов.
  - Документирован процесс отката в `docs/ROLLBACK.md`.
  - Документирован шаблон и регламент тестов в `docs/DIAGNOSTICS.md`.
  - Разработан безопасный скрипт экспресс-диагностики `diagnose_youtube.py`.

## [2026-09-25] Первичное восстановление и запуск NFQWS2

### Исправлено (fix):
- **Сбой opkg update:** системный симлинк `/opt/usr/bin/wget` вел на урезанный BusyBox; перенаправлен на `/opt/libexec/wget-ssl`.
- **YouTube разблокировка:** распакованы сжатые Lua-библиотеки в `/opt/etc/nfqws2/lua/*.gz` (`zapret-lib.lua`, `zapret-antidpi.lua`), без которых демон `nfqws2` пропускал пакеты без десинхронизации.
- **Blobs & Стратегии:** скопированы 28 бинарных blob-файлов и интерактивное меню `menu` (21 стратегия).
