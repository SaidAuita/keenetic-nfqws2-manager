# Журнал и шаблон диагностики YouTube & NFQWS2

Документ содержит правила проведения тестирования и стандартизированный шаблон фиксации результатов каждого прогона диагностики.

---

## 📋 Шаблон диагностической записи

Каждый тест или проверка после внесения изменений фиксируется по следующей форме (можно копировать в issue или вести в конце `CHANGELOG.md`):

```markdown
### [ТЕСТ] ГГГГ-ММ-ДД ЧЧ:ММ — <Краткое описание теста>

- **Дата и время:** `2026-10-11 13:00`
- **Версия / Коммит:** `commit <hash>` (версия NFQWS2: `1.3.1`)
- **Измененные параметры:**
  - `<название параметра или опции>`
- **Что проверялось:**
  - [ ] Воспроизведение YouTube на ПК (браузер)
  - [ ] Воспроизведение YouTube на Dune HD (комната / зал)
  - [ ] Стабильность стрима (просмотр > 5 минут без зависаний)
  - [ ] Проверка доступности googlevideo CDN
- **Результат SSH-подключения (порт 222):** `OK / FAIL`
- **Состояние службы NFQWS2:** `Running / Stopped / Error`
- **Результат проверки доступа к YouTube:**
  - `youtube.com` — HTTP 200 OK (TCP TLS)
  - `googlevideo.com` — HTTP 200 OK / chunks streaming
- **Обнаруженные ошибки:**
  - `Нет ошибок / Описание (например, зависание через 2 минуты на Dune HD)`
- **Дальнейшие действия:**
  - `Зафиксировать коммит / Откатить / Скорректировать стратегию`
```

## 🛠️ Скрипт автоматизированной диагностики

Для безопасного сбора диагностических данных без вывода паролей в терминал используйте скрипт:

```powershell
python diagnose_youtube.py
```

Скрипт проверяет:
1. Доступность SSH-сервиса на роутере (порт 222).
2. Статус службы `S51nfqws2`.
3. Установленную версию пакета в `opkg`.
4. Наличие блокировок `opkg.lock`.
5. Резолвинг ключевых доменов (`youtube.com`, `googlevideo.com`).
6. Доступность HTTPS TCP 443 к YouTube и Google Video CDN.
7. Состояние правил межсетевого экрана и портов QUIC.
